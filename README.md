
# TS Kanban Board

[![Демо](https://img.shields.io/badge/Демо-Запустить-00C853?logo=googlechrome&logoColor=white)](https://sofyapim.github.io/kanban-ts/)

Production-сборка канбан-доски на **TypeScript + Vite** с юнит-тестами (Vitest).
Репозиторий содержит готовый билд для **GitHub Pages** и работает как **PWA**.

## Возможности

- Три колонки: **Нужно сделать → В работе → Готово**
- Добавление, удаление и drag & drop задач
- Автосохранение в `localStorage`
- PWA: установка на главный экран и работа офлайн

## Установка PWA на телефон

1. Откройте [демо](https://sofyapim.github.io/kanban-ts/) в браузере телефона.
2. Меню браузера → **«Установить приложение»** (Chrome/Android)
   или **«Поделиться» → «На экран Домой»** (Safari/iOS).
3. Иконка появится на главном экране — приложение откроется отдельным окном
   и будет работать офлайн.
